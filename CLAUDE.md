## Project Overview

**BioPolars** is a high-performance bioinformatics library built as a native Rust + Polars plugin. It provides GPU-free, single-cell analysis operations that run entirely in Rust, exposed to Python via `pyo3-polars`.

## Architecture

```
biopolars/
├── src/                    # Rust source (pyo3-polars plugin)
│   ├── lib.rs              # Plugin entry point, expression registration
│   ├── svd.rs              # Sparse randomized SVD (single-svdlib)
│   ├── umap_binding.rs     # UMAP Python binding layer
│   ├── umap/               # Native UMAP implementation
│   │   ├── core.rs         # Main UMAP algorithm (run_umap)
│   │   ├── graph.rs        # Fuzzy simplicial set construction
│   │   ├── sgd.rs          # Stochastic gradient descent optimizer
│   │   ├── spectral.rs     # Spectral embedding initialization
│   │   └── utils.rs        # Distance functions, helpers
│   ├── leiden.rs            # Louvain/Leiden clustering
│   ├── deseq2.rs           # IRLS solver for differential expression
│   └── stats.rs            # Statistical functions (log1p, wilcoxon)
├── biopolars/              # Python package
│   ├── __init__.py         # BioPolarsExpr class (pl.Expr.bio namespace)
│   ├── core.py             # BioFrame data model
│   ├── io.py               # H5 → Parquet streaming converter
│   ├── pp.py               # Preprocessing (normalize, HVG)
│   └── tl.py               # Tools (PCA, sparse operations)
├── bench/                  # Benchmark scripts
├── Cargo.toml              # Rust dependencies
└── pyproject.toml          # Python build (maturin)
```

## Key API Pattern

All Rust functions are exposed as Polars expression plugins via the `.bio` namespace:

```python
import polars as pl
import biopolars

# SVD → UMAP pipeline
result = df.select(
    pl.col("cell_id").bio.svd(pl.col("gene_id"), pl.col("count"),
                               n_cells=20000, n_genes=28000, n_comps=50)
    .bio.umap(n_components=2, n_neighbors=15)
    .alias("umap_coords")
)
```

## Important Notes

- Rust plugin functions use `is_elementwise=False` since they are aggregate transforms
- Output types use custom `output_type_func` returning `List(List(Float32))` for nested array results
- The `AnyValue::List(series)` wrapper is required to return length-1 Series from aggregate plugins
- The `*.abi3.so` binary is generated by `maturin develop` and should not be committed
