- DESeq2: for designs with 3 or fewer residual degrees of freedom (for example 2 vs 2) the prior variance now equals R's value instead of differing by up to 50 %, because the random draws R uses are reproduced exactly; the 2 vs 2 and 3 vs 2 tests in `tests/test_deseq2_r_parity.py` fell outside R's own seed-to-seed range before.
- DESeq2: numeric contrasts test for all-zero genes on the original counts, as R and as tuple contrasts do (they disagreed for genes whose outlier counts were replaced). `min_replicates_for_replace < 3` and a pandas `obs` now raise (`ValueError`, `TypeError`); the Cook's cut-off is accurate to double precision.
- DESeq2: `DESeq2.last_results_info["na"]` tells apart missing p-values from genes without counts, from Cook's outliers and from independent filtering. The reference is now R 4.5.2 / DESeq2 1.50.2; `docs/deseq2.md` lists the differences to the 1.42 fixtures.
