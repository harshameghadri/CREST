- `tl.umap`: the spectral initialisation is now computed to a residual tolerance (restarted Lanczos) instead of a fixed 100 power-iteration steps, and a graph with several connected components is laid out component by component as in umap-learn. UMAP layouts therefore change compared with earlier releases. New argument `spectral_max_matvec` caps the work; a `RuntimeWarning` is issued if the cap is reached first.
- `harmony`: a fixed `lamb` of zero (or so small that the ridge system is singular), a negative `lamb` and a non-finite `lamb` now raise `ValueError` instead of silently returning the input unchanged or accepting the value. `lamb=None` and `lamb=-1` still estimate the ridge penalty.
