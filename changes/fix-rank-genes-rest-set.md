- `tl.rank_genes_groups`: with `groups=[...]` (a subset) or cells without a label, the "rest" of each group is now every other cell, as in scanpy (it used to be the other selected groups only, so `groups=["A", "B"]` compared A with B and a single group returned all-zero scores). A bare string for `groups` means one group.
- `tl.rank_genes_groups` raises `ValueError` for unknown group names (it returned an empty table), for groups with fewer than two cells and for a group that holds every cell; the arguments scanpy has and CREST does not (`reference`, `corr_method`, `pts`, ...) are listed in the quickstart.
